## ✨ Présentation

Portfolio personnel développé pour présenter mes projets, compétences et parcours. L'accent a été mis sur la **fluidité des animations**, les **transitions soignées** et une expérience utilisateur moderne, tout en restant performant et accessible.

## 🚀 Démarrage rapide

### Prérequis

- [Node.js](https://nodejs.org/) ≥ 18
- `npm`, `yarn`, `pnpm` ou `bun`

### Installation

```bash
# Cloner le dépôt
git clone https://github.com/Lenfos/Portfolio.git
cd Portfolio

# Installer les dépendances
npm install
```

### Lancer en développement

```bash
npm run dev
```

Ouvrir [http://localhost:3000](http://localhost:3000) dans votre navigateur.

> Le projet utilise **Turbopack** pour des rechargements ultra-rapides en développement.

### Build de production

```bash
npm run build
npm run start
```
